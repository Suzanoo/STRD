## Install and launch

Use Python 3.10+ with working Tk (Work exercised Python 3.12.14/Tk 9 on Linux).
Official python.org macOS installers include Tcl/Tk; see
https://www.python.org/download/mac/tcltk/ . First run `python3 -m tkinter`
and close the demonstration window. A Python without Tk cannot run this pilot.
From the repository root, with the delivered wheel path substituted:

```sh
python3 -m venv .venv-p1
.venv-p1/bin/python -m pip install --no-index --no-deps /PATH/strd_engine-0.3.0-py3-none-any.whl
.venv-p1/bin/python -m strd.desktop
```

The installed `.venv-p1/bin/strd-desktop` entry point is equivalent. For subsequent
launches from the repository, `bash scripts/start_p1_macos.command` uses that exact
venv without installing anything. No network is used by the application.
This is a Python/Tk pilot distribution, not a signed/notarized standalone macOS .app.
Do not install legacy requirements. Package import and headless use do not require Tk.

## Workflow

1. Start with a blank member. Select one of the two verified SYS H sections and
   enter member length in mm. Material is the bounded catalog SS400 record.
2. Review every applicability assertion; all start unchecked. Checking an assertion
   records user responsibility, not verification of bracing/support adequacy.
3. Define segments covering the member, without gaps/overlaps. Select a case and
   segment to enter corresponding M (kN-m), V (kN), Cb and provenance. Cases can
   independently use ASD or LRFD; demands are supplied by the user, never generated.
4. Calculate. Review the summary, every case/segment row, detailed intermediate
   quantities and full result trace. Known failures remain visible in incomplete runs.
5. Editing any engineering input immediately clears the old result. Recalculate
   explicitly. Selection alone does not invalidate results. A failed calculation
   never leaves a previous success visible.

Load demonstration fills the accepted A2 example, labels it as demonstration and
requires explicit calculation. Clear inputs and closing require confirmation.
Only one member exists in memory. Closing discards it; no Save/Open or project files.
The status CHECKS_PASS means only the implemented bending/shear checks passed under
recorded assumptions. It does not mean all member design checks passed.
Invalid input, unsupported scope, incomplete checks and strength failure remain distinct.

## Architecture and supported envelope

`strd.desktop.model.MemberSession` owns drafts, freshness and invokes unchanged
`strd.assessment.assess_member`. `ui` contains Tk widgets and presentation only.
`__main__` loads Tk lazily. No new engineering equations, catalog rows or materials.
The two verified A2 SYS sections and all A2 applicability limits remain authoritative;
see A2.md, A2_DATA.md and MS2.md. No analysis, axial/combined checks or bracing design.
English pilot labels, explicit units, scrollbars and keyboard tab navigation are used.
No persistence, PDF export, auto-updater, telemetry, installer or P2 work.
